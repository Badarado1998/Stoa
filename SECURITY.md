# Security

Please report vulnerabilities privately, never in a public issue or pull request:

- [Report a vulnerability](https://github.com/StoaDex/Stoa/security/advisories/new) on this repository, or
- a direct message to [@StoaDEX](https://x.com/StoaDEX) on X.

Stoa pays bug bounties in stablecoins, up to $2,500 for a critical issue. Scope, rewards and rules: [stoadex.com/docs/bug-bounty](https://stoadex.com/docs/bug-bounty).
