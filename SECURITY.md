# Security

Please report vulnerabilities privately, never in a public issue or pull request:

- [Report a vulnerability](https://github.com/StoaDex/Stoa/security/advisories/new) on this repository (preferred), or
- a direct message to [@StoaDEX](https://x.com/StoaDEX) on X, and we reply with a private channel.

Stoa no longer runs a paid bug bounty (the program ended on 17 November 2026); valid findings are credited in the security review if the reporter wishes. Full policy and scope: [.github/SECURITY.md](.github/SECURITY.md).
